# Атлас новогодних игр — Пётр Пустота

Новогодний каталог для видео «Что делает игру новогодней?»: 562 позиции,
источники, фильтры, сортировка, избранное и экспорт CSV / JSON / Markdown.

- [YouTube](https://www.youtube.com/@peterpustota)
- [Telegram](https://t.me/cyrikos)

## Сайт

Статический сайт находится в `index.html`. Аватар, иллюстрации, стили,
данные и скрипты встроены в один файл. Сборка и внешние зависимости не нужны.
Для локального просмотра откройте `index.html` в браузере.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**:

1. **Source:** Deploy from a branch.
2. **Branch:** main.
3. **Folder:** / (root).
4. Нажмите **Save** и дождитесь успешного развёртывания Pages.

Файл `.nojekyll` отключает обработку Jekyll. Обновления `index.html`,
отправленные в `main`, будут публиковаться через GitHub Pages.

## Данные

Каталог содержит ссылки на найденные публичные источники. Число источников
не равно числу игроков. Фильтры и поисковая разметка описывают этот корпус,
а не все обсуждения в интернете. Индивидуальные анкеты опроса в репозиторий
не включены.

## Страницы

- `index.html` — каталог, источники, фильтры и подарок.
- `nine.html` — девятка 3×3 с портретными обложками, поиском и экспортом PNG 1440×2460.
- `tierlist.html` — десять игр из видео, ряды S–D, перетаскивание и экспорт PNG.
- `credits.html` — автор, Telegram, Boosty, YouTube, источники иллюстраций.

Все страницы автономны: изображения, данные, стили и скрипты встроены.
Подборки сохраняются локально в браузере. Загрузка собственной обложки
не передаёт её на сервер. Для фотографий без найденной обложки используется
праздничная карточка. Повторный выбор одной игры в девятке блокируется.

При открытии «Мои 9 игр» сетка всегда пустая. Старый черновик загружается
только по кнопке «Восстановить черновик». Обложки доступны для расширенного
списка игр, в том числе популярных игр вне исследовательского корпуса.
